# Ressources

Références utilisées ou prévues par le projet.

## Documentation technique

- [Next.js Documentation](https://nextjs.org/docs) — App Router, routing et rendu serveur.
- [React Documentation](https://react.dev/) — composants, actions et interactions.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) — typage du projet.
- [Tailwind CSS v4 Documentation](https://tailwindcss.com/docs) — classes utilitaires et thème CSS.
- [PostCSS Documentation](https://postcss.org/docs/) — chaîne de transformation CSS.
- [ESLint Documentation](https://eslint.org/docs/latest/) — linting JavaScript/TypeScript.
- [GSAP Documentation](https://gsap.com/docs/v3/) — animations et timelines.

## E-commerce et contenu

- [Shopify Storefront API](https://shopify.dev/docs/api/storefront) — produits, variantes et panier via GraphQL.
- [Shopify GraphQL API Explorer](https://shopify.dev/docs/api/usage/api-exploring) — tester les requêtes Storefront.
- [Unsplash Source](https://unsplash.com/developers) — source des visuels de démonstration mentionnés dans le projet.

## Ressources du dépôt

- `README.md` — installation, branchement Shopify et prochaines étapes.
- `lib/shopify/` — client, types, mappers et opérations produits/panier.
- `lib/mock-data/` — données locales utilisées pour le développement.
- `public/` — assets visuels, audio et icônes de l'expérience rétro.
